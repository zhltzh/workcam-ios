# B 队列｜可信拍摄核心技术

共10项，P0。

## MAC-S01-B01｜可信拍摄事务

审计：

拍摄 → 原图暂存 → SHA-256 → 签名 → 证据记录 → 项目归属 → 原子提交。

确保任一步失败不产生虚假成功记录。

## MAC-S01-B02｜Secure Enclave 生命周期

检查密钥生成、保存、加载、锁屏、重启、失效和轮换。

不得静默降级为软件密钥。

无法证明硬件来源时明确显示未证明。

## MAC-S01-B03｜App Attest 客户端

完成真实 Apple API 接入准备：

- isSupported。
- generateKey。
- attestKey。
- generateAssertion。
- 服务端 Challenge。
- 失败及不支持状态。

模拟器仅测试状态和接口。

真实 Apple 证明必须由物理设备及服务端验证。

App Attest 不等于任意 Secure Enclave 签名密钥的硬件证明。

## MAC-S01-B04｜可信时间接入

接入 Windows TM10 时间不确定性算法。

区分：

- 系统时间。
- 服务端时间锚点。
- 单调时钟。
- 时间不确定区间。
- 锚点过期。
- 重启失效。
- 时钟异常。

未校准参数不得描述为认证精度。

## MAC-S01-B05｜离线时间状态

完善长时间离线、系统时钟调整、时区变化及重启处理。

时间未知必须显示 Unknown。

不得伪造精确可信拍摄时间。

## MAC-S01-B06｜Core Location 真实接入

采集：

- 经纬度。
- 水平精度。
- 垂直精度。
- 高度。
- 定位时间。
- 授权状态。
- 可用来源信息。

允许无网环境下获取可用定位。

不得承诺任何环境下都能获得 GNSS 定位。

## MAC-S01-B07｜定位质量引擎

接入 TM12。

识别陈旧定位、低精度、异常跳变、人工输入及系统可提供的模拟来源信号。

风险信号不等于确定作弊。

## MAC-S01-B08｜离线可信状态展示

明确展示：

- Local Capture。
- Integrity Verified。
- Signature Valid。
- Device Attestation。
- Time Source。
- Location Quality。
- Server Verification。

禁止使用误导性的统一可信总分。

## MAC-S01-B09｜证据协议兼容

接入 TM01、TM02 固定测试向量。

验证 UTF-8、CRLF、DER、Base64、序号、历史版本和结构化定位边界。

保持现有生产协议兼容。

新协议在独立候选中验证。

## MAC-S01-B10｜证据独立验证

使用历史真机证据及模拟器新证据。

分别执行：

- Swift 本地验证。
- 固定后端验证。
- W018 CLI 验证。
- 单字节篡改测试。
- 缺失 DER 测试。
- 错误项目关联测试。

项目归属若未纳入签名载荷，不得宣称已获得密码学证明。
