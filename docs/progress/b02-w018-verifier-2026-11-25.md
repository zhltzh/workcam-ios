## 4. 六层级与退出码（摘要，契约全文见报告格式文档）

- L1 文件完整性 / L2 数学签名 / L3 已注册设备身份 / L4 硬件密钥来源 /
  L5 可信时间 / L6 定位来源——逐层报告，绝不合并；
- L4 离线恒 `not_verifiable_offline`（签名有效绝不解释为硬件来源证明）；
- L6 恒附注「签名只固定坐标字节，坐标来源 GPS/手动离线不可证」；
- 退出码：0 全过 / 1 验证失败（含篡改、缺件、锚点验签失败、孤儿文件）/
  2 包格式损坏（zip-slip、坏 zip、package.json 不可读、炸弹防护、
  输入不存在；argparse 用法错误同为 2）。

## 6. Mac 端接入（如何导出可验证证据包）

1. 按 T13 v1 组包：`package.json` + `photos/` + `manifests/`
   （每张照片一份已签名 SignatureManifest，ECDSA P-256 + SHA-256 over
   canonical payload，跨语言字节合同 `test-vectors/fixed-vectors.json`）+
   可选 `derivatives/`（衍生图回链）与 `receipts/`（时间锚点回执）；
   构建器 `backend/techlab/evidence_package.py::build_package()`。
2. zip 两种布局均支持：zip 根即包内容（`cd <pkg> && zip -r ../a.zip .`）
   或单顶层目录包裹（Finder「压缩」默认布局）。
3. 接收方本地准备（可选）：`--registry registry.json`（L3）、
   `--anchor-pubkey server_key.pem --anchor-key-id <id>`（L5）。
4. 验证命令见 `tools/evidence-verifier/README.md`；无需账号，默认离线，
   照片不上传。
