## 7. Review findings frozen in the vectors (see proposal doc)

- F1: Swift M003 `EvidenceManifest.payload()` hardcodes `location=none`
  (location is `String?`); backend supports structured non-null
  locations — the two producers cannot agree on non-empty location bytes.
- F2: v1.0 float embedding uses Python repr semantics (drift risk).
- F3: v1.1 float rule is portable only as a whole (integer branch,
  `-0.0`, `.0` padding).
- F4: production serializer falls back to the v1.0 domain separator for
  unknown versions (measured: version "2.0" → domain `WorkCam-Sig-v1`;
  structure validation rejects it; Swift must reject before
  serialization instead).
- F5: ISO8601 check is shape-only (month 13 passes).
- F6: DER structural check does not enforce INTEGER minimality (BER
  non-minimal r accepted by the structure check; crypto verification
  fails on it — measured, not guessed).
