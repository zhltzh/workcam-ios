## Mac 端部署说明要点

1. `brew install python@3.12`（或任意 3.12+）；无需其他系统依赖（SQLite 随 Python 附带）
2. `cd backend && ./bootstrap.sh`（可 `--locked` 用精确版本）
3. `cp .env.development.example .env.development`，填 `WORKCAM_ENROLLMENT_CODE`（`python -c "import secrets; print(secrets.token_urlsafe(32))"` 生成）
4. `./scripts/start_dev.sh`（热重载）或 `./scripts/start_prod.sh`（默认 .env.production + 4 worker，均绑 127.0.0.1）
5. `./scripts/run_tests.sh` 全量；`--seed 0` 复现哈希敏感问题
6. `./scripts/backup.sh OUT_DIR` / `./scripts/restore.sh BACKUP_DIR TARGET_DB` 走同一 db_tools 核心
7. 健康检查、迁移演练、env 安全等级与 Windows 端完全一致——CLI 与 Python 层无平台分支，仅启动包装不同
