## 原型缺陷修复

- `camera-hut-item` 拼写 → `camera-hud-item`
- `aspect-r` 无效属性 → `aspect-ratio`
- `showPage` 隐式全局 `event` → `data-page` 显式高亮（photo-detail / report-preview 二级页正确回亮父导航）

## 过程发现（记录防复发）

- **Playwright 截图时必须禁用 transition**：`.btn { transition: background .15s }` 会在截图等待窗口内产生中间色；本次实测中同步读取 computedStyle 读到过渡起点，造成"按钮背景不随主题切换"假象。已将 transition-property 改为 `background-color`（longhand），截图流程统一注入 `* { transition: none !important; }`。
- Playwright MCP 禁 `file:` 协议：原型验证需本地 HTTP 伺服（`python -m http.server`）。
