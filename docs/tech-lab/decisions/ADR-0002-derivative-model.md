# ADR-0002：原图不可变 + 衍生图哈希回链的数据结构

状态：已接受 · 日期：2026-11-19 · 关联：T05、T10、T13

## 背景

水印、标注、报告页都是对照片的加工。竞品常见错误是直接改写文件或加工后丢失与原始证据的关联。产品原则要求"修改水印不破坏原始证据""导出可追溯原图"。

## 决策

1. **原图文件写盘后只读**（read-only），任何加工产物写入独立的 `derivatives/` 层，绝不回写原图路径。
2. 衍生图必须携带结构化头部（JSON sidecar 或嵌入 XMP）：
   - `original_photo_hash`（链回原图，验证包可校验）；
   - `derivative_hash`（自身内容哈希）；
   - `recipe`（模板版本+参数，如水印布局、字段值），同 recipe 应可复现同一衍生图；
   - `applied_at` 与操作序列号。
3. 追溯链：`衍生图 → original_photo_hash → 已签名 manifest.photo_hash`。签名只覆盖原图，衍生图**永远不冒充原始证据**。
4. 校验规则（自动化测试强制）：
   - 原图哈希与磁盘字节不一致 → 证据损坏（fatal）；
   - 衍生图缺失 original 回链 → 拒绝入证据包；
   - 对原图路径的任何写尝试 → 测试必须失败。

## 后果

- T10 水印引擎只产出衍生图；T09 导出天然区分原件/加工件；T13 证据包可包含"原图+签名+衍生图+回链校验"完整闭环。
- 首版实现为 sidecar JSON（`backend/techlab/derivative_model.py`），iOS 端渲染由 Mac 在真机验证。
