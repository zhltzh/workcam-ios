## 关键依赖规则

| 上游 | 下游 | 原因 |
|---|---|---|
| T01 | T05 | 衍生图必须能回溯到已签名的原图哈希 |
| T05 | T10 | 水印是衍生图的一种，禁止改原图 |
| T05 | T09 | 导出必须区分原图/衍生图身份 |
| T05+T03+T02 | T13 | 证据包绑定：内容哈希+时间锚+定位元数据 |
| T13 | T18 | 独立验证工具消费证据包格式 |
| T11 | T09 | 批量导出需要可遍历的项目数据层 |
| T06 | T11 | 数据库可靠性是一切离线功能的地基 |
